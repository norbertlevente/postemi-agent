Postemi is a social media scheduler. You write a post once, pick the channels, and Postemi publishes it at the right time on 37 platforms and apps: Instagram, TikTok, Facebook, LinkedIn, X, YouTube, Threads, Bluesky, Pinterest, Discord, Telegram, Slack, Mastodon, communities like Lemmy and Circle, blogs like WordPress, Ghost, Tumblr and Dev.to, team chats like Microsoft Teams and Google Chat, and newsletters like Mailchimp, Kit, MailerLite and Brevo.

It always shows a preview first, and you confirm before anything is saved. There is also a command line tool (`npm install -g postemi`) and a public REST API.

**Fair pricing.** Every plan starts with a 7-day free trial. Plans start at 19 a month in euros, US dollars or Swiss francs, with VAT included in euros and francs. Yearly billing gives you 3 months free. If you get stuck, Norbert, the founder, replies.

## FAQ

**Which networks does Postemi post to?**
37 platforms and apps today, including Instagram, TikTok, Facebook, LinkedIn, X, YouTube, Threads, Bluesky, Pinterest, Discord, Telegram, Slack, Mastodon, WordPress and newsletters such as Mailchimp, Kit and Brevo. Google Business Profile and Snapchat are coming soon.

**Can my AI agent post for me?**
Yes. Add the MCP server https://mcp.postemi.com/mcp to Claude, ChatGPT, Cursor, VS Code or any MCP client and sign in in the browser. The agent shows you a preview and schedules the post once you confirm. MCP, the CLI and the REST API are part of the Pro, Creator and Team plans.

**Do I need an API key?**
No. Clients that support OAuth open the Postemi sign-in page, and you approve one workspace. For scripts and clients without OAuth, create an MCP key on the API keys page in the app and send it as `Authorization: Bearer <key>`.

**How much does it cost?**
Every plan starts with a 7-day free trial. Plans start at 19 a month (Basic), and AI agent access starts at 29 a month (Pro). You pay in euros, US dollars or Swiss francs; euro and franc prices include VAT. Yearly billing gives you 3 months free, and you can cancel anytime.

**Can I post different text to each network?**
Yes. Write once for all channels, or switch to different text per channel. Threads, first comments and network options such as Instagram reels and stories are set per channel too.

## MCP connection

| Field | Value |
|---|---|
| Server URL | `https://mcp.postemi.com/mcp` |
| Transport | Streamable HTTP |
| Auth | OAuth 2.1 in the browser (dynamic client registration, no key needed) |
| Auth for scripts | MCP key from https://postemi.com/app/api-keys, sent as `Authorization: Bearer <key>` |
| OAuth metadata | `https://mcp.postemi.com/.well-known/oauth-protected-resource` |
| Scopes | `posts:read`, `posts:draft`, `posts:publish`, `channels:read`, `channels:write`, `media:write`, `analytics:read`, `mcp:read`, `mcp:write` |
| Plan | Pro, Creator or Team (7-day free trial) |
| Docs | https://postemi.com/docs/mcp |
| Registry name | `com.postemi/postemi` |

Tools:

| Tool | What it does |
|---|---|
| `get_workspace_context` | Current time and your timezone, so dates are right |
| `list_workspaces`, `switch_workspace` | See your workspaces and move the connection |
| `list_integrations` | Your connected channels and their handles |
| `list_groups` | Your brands (channel groups) |
| `get_integration_schema` | The rules and character limit for one channel |
| `get_channel_options` | Ids for settings such as a board or a category |
| `preview_post` | Shows the post, the time and any problem; writes nothing |
| `create_post` | Schedules, publishes or drafts the post |
| `list_posts`, `delete_post` | Read the calendar and take back a scheduled post |
| `upload_media_from_url` | Adds an image or video from a URL or a file |
| `create_upload_link`, `list_upload_link_files` | A browser upload page for big files (videos up to 1 GB) |
| `get_plans`, `subscribe`, `get_subscription`, `manage_subscription` | Plans and billing, only when you ask |

## Install snippets

### Claude (claude.ai and Claude Desktop)

Customize, Connectors, "Add custom connector". Paste the URL, select Add, then Connect and sign in to Postemi.

```text
https://mcp.postemi.com/mcp
```

### Claude Code

```bash
claude mcp add --transport http --scope user postemi https://mcp.postemi.com/mcp
```

Then `/mcp`, choose postemi, Authenticate. Or the plugin with skills:

```bash
claude plugin marketplace add norbertlevente/postemi-agent
claude plugin install postemi@postemi-agent
```

### ChatGPT

On chatgpt.com/plugins, choose the plus button, then "Add custom MCP server".

```text
Name: Postemi
URL: https://mcp.postemi.com/mcp
Authentication: OAuth
```

### Cursor

One click: `cursor://anysphere.cursor-deeplink/mcp/install?name=postemi&config=eyJ1cmwiOiJodHRwczovL21jcC5wb3N0ZW1pLmNvbS9tY3AifQ==`

Or `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "postemi": {
      "url": "https://mcp.postemi.com/mcp"
    }
  }
}
```

### VS Code (GitHub Copilot agent mode)

```bash
code --add-mcp '{"name":"postemi","type":"http","url":"https://mcp.postemi.com/mcp"}'
```

Or `.vscode/mcp.json`:

```json
{
  "servers": {
    "postemi": {
      "type": "http",
```
